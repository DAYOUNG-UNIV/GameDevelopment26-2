다시 하기 — 시간부터 되돌립니다

6주차 복습 퀴즈 14번, 다시 시작했더니 공이 얼어붙은 그 문제입니다.

끝날 때 Time.timeScale = 0 으로 멈춰 두었다면, 그 값은 씬을 다시 불러와도 그대로입니다.

씬에 걸린 값이 아니라 게임 전체에 걸린 값이라서요.

버튼 연결

Title — START → LoadGame · QUIT → Quit

Result — RETRY → LoadGame · TITLE → LoadTitle

timeScale 을 쓰지 않았다면 이 줄은 있어도 아무 해가 없습니다.

SceneLoader.cs — 완성
using UnityEngine; using UnityEngine.SceneManagement; public class SceneLoader : MonoBehaviour { public void LoadGame() { Time.timeScale = 1f; // 멈춘 시간을 먼저 되돌린다 SceneManager.LoadScene("Game"); } public void LoadTitle() { Time.timeScale = 1f; SceneManager.LoadScene("Title"); } public void Quit() { Application.Quit(); // 빌드에서만 동작 } }

한 판 점검 — Title 에서 Play

Game 씬을 연 채 Play 를 누르면 Title 을 건너뜁니다. 점검할 때는 Title 씬을 열고 누르세요.

START 를 누르면 Game 으로 넘어간다

다 모으면 Result 에 CLEAR! 와 점수가 보인다

지면 Result 에 GAME OVER 가 보인다

RETRY 를 누르면 처음 상태로 돌아가고, 공이 움직인다

TITLE 을 누르면 시작 화면으로 돌아간다

하는 중에 Esc 를 누르면 시작 화면으로 돌아간다

이 여섯 줄이 되면 에디터 안에서는 한 판이 끝까지 돕니다. 이제 에디터 밖으로 꺼냅니다.
