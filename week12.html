씬을 넘기는 SceneLoader 스크립트

버튼이 부를 함수 셋을 한 파일에 둬요. 함수는 public void 여야 버튼 목록에 나와요

Assets/Scripts/SceneLoader.cs — 파일 이름 = class 이름
using UnityEngine; using UnityEngine.SceneManagement; public class SceneLoader : MonoBehaviour { public void LoadGame() // START · RETRY { Time.timeScale = 1f; // 멈춘 시간을 먼저 되돌린다 SceneManager.LoadScene("Game"); } public void LoadTitle() // TITLE { Time.timeScale = 1f; SceneManager.LoadScene("Title"); } public void Quit() // QUIT { Application.Quit(); // 빌드에서만 꺼진다 } }
"Game" 은 씬 파일 이름 그대로

대문자 · 띄어쓰기까지 같게. 씬 이름을 바꾸면 여기도 같이 바꿔요

Time.timeScale = 1f

게임 오버에서 시간을 0 으로 멈췄다면, 씬을 다시 불러와도 0 그대로예요. 새 판 전에 1 로

Quit 은 에디터에서 아무 일도 없어요

에디터 Play 중에는 꺼지지 않는 게 정상이에요. 빌드에서 확인해요

게임 중에 Esc 로 Title 가기

테스터가 한 판을 그만두고 싶을 때 지킴이를 부르지 않아도 되게. Game 씬의 빈 오브젝트에 붙여요

EscToTitle.cs — Game 씬에만
using UnityEngine; using UnityEngine.InputSystem; using UnityEngine.SceneManagement; public class EscToTitle : MonoBehaviour { void Update() { if (Keyboard.current.escapeKey.wasPressedThisFrame) { Time.timeScale = 1f; SceneManager.LoadScene("Title"); } } }
입력 방식이 둘이에요

Roll a Ball 처럼 Input System 패키지를 쓰는 프로젝트는 왼쪽 코드. 예전 방식이면 Input.GetKeyDown(KeyCode.Escape)

이 에러가 뜨면 왼쪽 코드로

InvalidOperationException: You are trying to read Input using the UnityEngine.Input class, but you have switched active Input handling to Input System package …

어느 쪽인지 보는 곳

Edit → Project Settings → Player → Other Settings 의 Active Input Handling

확인 기준 1 · 베타 한 문장 — 알파와 같은 틀

「번에서 이(가) 해 본 사람의 이면 확인된 것으로 본다.」

예) 1번에서 4 ~ 5 가 해 본 사람의 절반 이상이면 확인된 것으로 본다.

확인 기준 2 · 고친 것 — 알파 숫자와 나란히

「알파에서 이(가) 명 중 명이었다. 베타 번에서 이(가) 이하이면 고친 것이 통한 것으로 본다.」

예) 알파에서 「적이 움직이는 줄 몰랐다」가 15명 중 5명이었다. 베타 4번에서 「한 번 닿고 나서 · 끝까지 몰랐다」가 해 본 사람의 5분의 1 이하이면 고친 것이 통한 것으로 본다.
