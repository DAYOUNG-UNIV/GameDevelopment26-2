RETRY 가 이상하면 — 씬을 다시 불러와도 남는 것

SceneManager.LoadScene 은 그 씬의 오브젝트만 새로 만듭니다. 이 셋은 그대로 남습니다

1
Time.timeScale

게임 오버에서 0 으로 멈췄다면 다음 판도 멈춘 채 시작합니다

증상 — 공이 안 움직인다

2
static 변수

9주차 GameResult 가 점수를 Result 씬으로 넘길 수 있던 바로 그 성질입니다

증상 — 목숨 · 점수가 이어진다

3
DontDestroyOnLoad

씬을 넘어 살아남는 오브젝트. 그 씬으로 돌아올 때마다 하나씩 더 생깁니다

증상 — 음악 · 소리가 겹친다

SceneLoader.cs — 새 판을 부르기 전에
public void LoadGame() { Time.timeScale = 1f; // ① 멈춘 시간 GameState.lives = 3; // ② static 값은 직접 처음으로 SceneManager.LoadScene("Game"); }
MusicPlayer.cs — 하나만 남기기
static MusicPlayer instance; void Awake() { if (instance != null) { Destroy(gameObject); return; } // ③ instance = this; DontDestroyOnLoad(gameObject); }

RETRY 는 빌드에서 두 번 이상 연달아 눌러 봅니다. 한 번은 되고 두 번째에 터지는 일이 많습니다

노트북마다 속도가 다르면 — 프레임과 Time.deltaTime

Update 는 1초에 화면을 그리는 수만큼 불립니다. 그 수가 노트북마다, 에디터와 빌드마다 다릅니다

Update 한 번에 0.1 씩 움직이면
60 프레임
1초에 6
144 프레임
1초에 14.4

같은 코드인데 2.4배 빠릅니다. 적이 피할 틈 없이 날아옵니다

힘을 주는 코드는 FixedUpdate

FixedUpdate 는 프레임과 상관없이 1초에 정해진 횟수만 불립니다. Roll a Ball 의 AddForce 가 FixedUpdate 에 있는 이유입니다

✗ 노트북마다 속도가 달라짐
transform.position += Vector3.right * 0.1f;
✓ 1초에 3 만큼 — 어느 노트북에서나 같음
transform.position += Vector3.right * 3f * Time.deltaTime;
느린 노트북 흉내 — 아무 스크립트의 Start 에 잠깐 QualitySettings.vSyncCount = 0; Application.targetFrameRate = 20; 두 줄을 넣고 Play. 속도가 그대로면 통과입니다. 확인한 뒤 지웁니다
AI 가 준 움직임 코드에서 가장 먼저 볼 곳이 Time.deltaTime 입니다

using UnityEngine; using UnityEditor; // 빌드에서 여기가 걸림 public void Quit() { EditorApplication.isPlaying = false; }

AI 는 코드만 봅니다. 유니티는 코드 밖에도 연결을 저장합니다. 그 연결이 끊어지는 다섯 곳

AI 가 한 일유니티에서 생기는 일그래서 팀 약속
파일 · class 이름을 바꿨다오브젝트에 Missing (Mono Script). 유니티는 스크립트를 이름이 아니라 .meta 파일 속 번호(GUID)로 기억하고, 파일 이름 = class 이름이어야 붙습니다이름 · 위치는 바꾸지 않는다. 꼭 바꿀 때는 유니티 Project 창에서
변수 이름을 「더 좋은 이름」으로 바꿨다Inspector 에 끌어다 놓은 칸이 비어 버림. 칸의 값은 변수 이름으로 저장됩니다Inspector 에 보이는 변수 이름은 그대로
둘이 같은 씬을 고쳤다씬은 파일 하나. 나중에 넣은 쪽이 앞의 것을 덮습니다씬은 한 사람. AI 작업은 Test_이름 씬 · 프리팹으로
새 Tag · Layer · 패키지를 쓰라고 했다내 프로젝트에만 생김. 합치면 Tag: Enemy is not defined · 없는 패키지로 빨간 줄프로젝트 설정 · 패키지는 팀에 먼저. 합치는 사람이 넣는다
UnityEditor 코드를 넣었다에디터에서는 되는데 빌드가 안 만들어짐 — 앞에서 본 것#if UNITY_EDITOR 안에만
