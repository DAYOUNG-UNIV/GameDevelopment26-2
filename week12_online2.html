편 A 와 잇기 — 맞을 때 가장자리 빨갛게

Volume 하나 더. 평소 Weight 0, 맞는 순간 1 → 0.

Count: 3
WWeight — 얼마나 섞을지 (0 ~ 1)

같은 방법: 체력이 낮을 때 회색 · 아이템을 먹을 때 잠깐 밝게

Feedback.cs 에 더하는 줄
using UnityEngine.Rendering;            // 맨 위

    public Volume flashVolume;            // HitVolume

    // Play() 끝에
    if (flashVolume != null) StartCoroutine(VolumePulse());

    IEnumerator VolumePulse()
    {
        float t = 0f, time = 0.3f;
        while (t < time)
        {
            t += Time.unscaledDeltaTime;
            flashVolume.weight = 1f - t / time;
            yield return null;
        }
        flashVolume.weight = 0f;
    }
