찾기는 한 번만

Update 안의 Find 는 1초에 60번 × 적 40마리 = 2400번.

느린 판
void Update()
{
    Transform player = GameObject.Find("Player").transform;
    transform.position = Vector3.MoveTowards(
        transform.position, player.position,
        speed * Time.deltaTime);
}
고친 판 — EnemyChase.cs
Transform player;                 // 담아 둘 칸

void Start()
{
    player = GameObject.FindWithTag("Player").transform;
}

void Update()
{
    transform.position = Vector3.MoveTowards(
        transform.position, player.position,
        speed * Time.deltaTime);
}

더 좋은 방법: public 칸에 끌어다 놓기 — 프리팹으로 나중에 생기는 적은 위처럼 시작할 때 찾기

지우지 말고 다시 쓰기 — 오브젝트 풀

Instantiate 대신 pool.Get, Destroy 대신 pool.Release.

!처음 상태로 되돌리기는 OnEnable 에
Shooter.cs (줄임) — using UnityEngine.Pool;
pool = new ObjectPool<GameObject>(
    () => Instantiate(bulletPrefab),   // 모자랄 때만 새로
    b => b.SetActive(true),             // 꺼낼 때
    b => b.SetActive(false),            // 돌려놓을 때
    b => Destroy(b),                    // 너무 많을 때
    true, 20, 100);

GameObject b = pool.Get();             // Instantiate 대신

// Bullet.cs
void OnEnable() { life = 2f; }         // 꺼낼 때마다 처음 상태로
pool.Release(gameObject);              // Destroy 대신

자주 바뀌는 UI 는 다른 Canvas 로

글자 하나가 바뀌면 그 Canvas 전체를 다시 계산합니다.

한 Canvas 에 다
Canvas
├ MenuPanel · Background
├ Title · Buttons
└ Timer · Score ← 매 프레임
나누면
Canvas — 가만있는 것
├ MenuPanel · Background · Title

└ Timer · Score

마우스 확인이 줄고, 버튼 위 글자가 클릭을 막는 문제도 사라집니다

프레임과 시간

60Hz 노트북과 144Hz 모니터에서 같은 속도로.

VSync Count: Every V Blank
모니터에 맞춰 그림 — 60번일 수도 144번일 수도
움직임에는 Time.deltaTime
1초에 가는 거리가 같아짐. Update 에서 transform 을 움직이는 코드
상한: Application.targetFrameRate
VSync 가 켜져 있으면 무시됨 — 둘 중 하나만
// 프레임마다 0.1 씩 — 144Hz 에서 2.4배 빠름
transform.Translate(0, 0, 0.1f);

// 1초에 6 씩 — 어디서나 같음
transform.Translate(0, 0, 6f * Time.deltaTime);

// 상한을 두려면 (VSync 를 끈 경우)
Application.targetFrameRate = 60;
